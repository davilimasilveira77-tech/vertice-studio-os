VÉRTICE STUDIO OS — MEMÓRIA ATIVA

COMO FUNCIONA A MEMÓRIA
- Tudo que você cadastrar é salvo automaticamente no navegador.
- Fechar e abrir a página não apaga os dados.
- O app também cria uma cópia de segurança local automática.
- A cada 30 segundos ele reforça o salvamento.
- Use Configurações > Exportar para criar um arquivo de backup.

IMPORTANTE
- A memória é local por navegador/dispositivo.
- Se você cadastrar no computador, o celular NÃO verá automaticamente os mesmos dados.
- Para sincronizar celular e computador será necessário um banco de dados online e login.

GITHUB PAGES
1. Renomeie o arquivo vertice-studio-os-memoria.html para index.html, se quiser.
2. Envie ao repositório.
